隱私權保護政策與使用者條款

歡迎您使用 Blackboard Cam (黑板筆記相機)（以下簡稱「本服務」）。為保護您的個人資料隱私與開發者權益，在您開始使用本服務之前，請詳細閱讀以下隱私權保護政策與使用者服務條款：

【核心政策聲明】
本服務致力於保護您的資料隱私。所有收集之照片與黑板筆記資料僅用於為您提供 AI 生成摘要、總結與課程整理服務，絕不用於廣告投放，亦不會出售給任何第三方。

一、 我們收集與處理的資料

  • 相機與媒體庫存取權限：本服務需要存取您的相機以拍攝黑板照片，並需要讀寫媒體庫權限以將整理後的光學校正影像安全存儲於您手機的 Pictures/BlackboardCam 目錄。
  • Google 帳號資訊：為了提供您每日免費的分析額度與安全同步服務，本服務使用 Firebase Authentication 進行 Google 帳號登入，我們會儲存您的 Email 地址與公開名稱。
  • API 金鑰與提示詞設定：如果您配置了個人 Gemini API 金鑰或自訂提示詞，這些敏感資訊均經過安全加密技術處理，確保您的密鑰安全不外洩。

二、 資料如何被使用與傳輸

當您點選「生成 AI 筆記」時，本服務會透過安全加密（HTTPS）管道，將黑板照片中的零碎重點文字或影像區塊傳輸至 Google Gemini API 進行概念整理與筆記摘要生成。本服務不會常設性地在雲端伺服器備份或保留您的原始黑板相片檔案，所有實體檔案均妥善保存在您的本機裝置中。

三、 AI 服務免責聲明

本服務使用 Google 最新的 Gemini 視覺與語言大模型來解析黑板內容。請注意：

  • AI 所生成之所有內容（包含但不限於公式推導、概念解釋、文字摘要等）皆為自動生成，僅供學習參考之用。
  • 開發團隊無法保證 AI 產出內容之 100% 準確性與真實性。使用者應自行核對與評估其內容。因信賴 AI 產出內容而導致之任何損失，本 App 及其開發團隊不承擔任何法律與賠償責任。

四、 訂閱與免費額度規範

本服務提供之每日免費額度（如每日 5 次筆記分析與 2 次學期總結）屬於免費贈送性質。開發團隊有權隨時因應 API 維護成本或營運策略，調整免費額度、重置規則或資費方案。

五、 用戶刪除資料權益

您有權隨時在 App 中登出您的帳號。若您希望完全刪除您的註冊資料（如登入 Email 等雲端帳戶資訊），可以聯絡我們的開發團隊，我們將在收到請求後 3 個工作天內為您完成雲端資料清除。
